Wells needed versus V for the selected K values and layouts.

N is the total number of wells (tubes). Counts include the empty slots a layout reserves but never fills, as the Diana tool does. 2D Fragmented: N = 2K·ceil(V/K²). 2D Matrix: N = 2s·ceil(s/K), s = ceil(√V). 3D: N = 3c·ceil(c²/K), c = ceil(∛V). No pooling: one guide per well, N = V. These are well counts only; they say nothing about how reliably each layout decodes a screen.
